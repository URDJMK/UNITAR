# Visual Asset Credits

All five raster visuals in this package were generated specifically for this fictional, offline demonstration using OpenAI's built-in image-generation tool on 2026-08-04. They are not photographs of real actors or production evidence.

## Cinematic scene

- `scene-wide.webp` — fictional woman entering a rain-soaked mid-century house at midnight; wide shot.
- `scene-medium.webp` — the same scene reframed as a medium shot.
- `scene-closeup.webp` — the same scene reframed as a close-up.
- `generated-storyboard.webp` — a three-panel editorial storyboard composed from the wide, medium, and close-up scene frames.

Prompt direction: premium cinematic suspense, cold blue-gray moonlight, restrained amber practical light, charcoal presentation palette, no text, logos, watermark, weapons, gore, public figures, or extra people.

## Fictional scan subject

- `daniel-base.webp` — DANIEL, an original fictional background actor in a dark studio, created without reference to any known actor, celebrity, politician, or real person.

Prompt direction: semi-realistic, humane three-quarter-length portrait, unbranded clothing, neutral documentary mood, charcoal/slate palette with muted teal and amber rim lighting, no text, logos, watermark, or interface graphics.

Person outlines, background masks, scan overlays, tracking nodes, arrows, film grain, and transitions are implemented locally with HTML, CSS, and JavaScript.
